How to Use the Knowledge Graph

Interactions

Click on a Node

Click any concept node to view detailed information about that topic.

Right Click and Hold

Right click and hold on a concept node to open the quick actions menu: mark understanding, show related concepts, show course nodes.

Filters & Search

Filters

Use filters to filter by understanding status, or focus views by filtering by course, materials, or slides.

Search Concepts

Use the search bar to quickly find specific concepts in your knowledge graph.

Node Size Reflects how many courses the concept appears in
Top-N Concepts Main concepts are ranked by weight
View Modes: Use the radio buttons on the left to change the graph view between Knowledge State, Interest Level, and Engagement Level.
